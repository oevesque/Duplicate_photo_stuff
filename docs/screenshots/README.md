Déposer ici les images référencées par le README principal, avec exactement ces noms :

| Fichier attendu | Contenu |

| `onglet2-recherche.png` | Onglet 2 avec des résultats affichés dans les deux panneaux |

## Conseils

- **Format** : PNG, largeur 1200–1600 px. Éviter les fichiers de plus de 500 Ko.
- **Confidentialité** : les chemins de fichiers affichés seront publics. Utiliser des dossiers de démo ou flouter les chemins personnels avant de publier.
- **Capture** : `Win + Maj + S` (outil Capture d'écran Windows) ou `Alt + Impr. écran` pour la fenêtre active.
